Política de Privacidade — PsyMap

Última atualização: 04 de julho de 2026

O PsyMap é um aplicativo de mapeamento emocional desenvolvido por Wennington Dias. Esta política descreve como o aplicativo trata os dados dos seus usuários.

Coleta de Dados

O PsyMap não coleta, armazena na nuvem ou transmite nenhum dado pessoal. Todos os registros de humor, emoções, notas e configurações ficam exclusivamente armazenados no dispositivo do usuário, utilizando o sistema de armazenamento local (AsyncStorage).

Dados Armazenados Localmente

O seguinte conteúdo é salvo apenas no seu dispositivo:

  • Registros de humor (emoção, intensidade, data e nota opcional)
  • Emoções customizadas criadas pelo usuário
  • Preferência de tema visual
  • Preferência de notificações

Esses dados não saem do seu dispositivo. Se você desinstalar o aplicativo, todos os dados serão perdidos permanentemente.

Permissões

O PsyMap pode solicitar as seguintes permissões opcionais:

  • Notificações — utilizada exclusivamente para enviar lembretes locais (3 vezes ao dia) para incentivar o registro de humor. As notificações são agendadas localmente no dispositivo. Nenhum dado é enviado a servidores externos.

O aplicativo não solicita acesso à câmera, microfone, localização, contatos, armazenamento de arquivos ou qualquer outra permissão sensível.

Compartilhamento de Dados

O PsyMap não compartilha dados com terceiros, serviços de analytics, redes publicitárias ou qualquer outro serviço externo.

As funções de compartilhamento (exportar PDF, compartilhar o app) são iniciadas exclusivamente pelo usuário e utilizam os recursos nativos do sistema operacional.

Internet

O PsyMap funciona 100% offline. O único uso de internet ocorre quando o usuário solicita explicitamente ações como enviar feedback por e-mail, que utiliza o aplicativo de e-mail do dispositivo.

Segurança

Como todos os dados são armazenados localmente no dispositivo, a segurança dos dados depende das configurações de segurança do próprio dispositivo (bloqueio de tela, criptografia, etc.).

Crianças

O PsyMap não coleta dados de nenhum usuário, incluindo crianças. O aplicativo não possui restrição de idade, mas não é direcionado especificamente a menores.

Alterações nesta Política

Qualquer alteração nesta política será publicada nesta página com a data de atualização revisada. Recomendamos que os usuários consultem esta política periodicamente.
